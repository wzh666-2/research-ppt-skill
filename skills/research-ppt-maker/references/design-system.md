# Original visual system

The system is independently designed and must not imitate a supplied template's exact geometry.

## Palette

- Canvas: warm ivory `#F7F3EA`
- Ink: deep ink navy `#18313A`
- Emphasis: sea teal `#1F7A78`
- Status: amber `#D79A2B`
- Risk: terracotta `#C65F46`
- Secondary text: slate `#66737A`
- Dividers: mineral gray `#D8D4C8`

## Typography and hierarchy

- Chinese: Microsoft YaHei; English fallback: Aptos.
- Deck title 28–34 pt; slide title 24–28 pt; body 15–19 pt; labels 10–12 pt.
- Use conclusion-led titles. Keep one core conclusion per slide.
- Default to left alignment and generous margins. Avoid centered body text.

## Layout logic

- 16:9, twelve-column conceptual grid, 48–64 px equivalent outer margins.
- Vary compositions: full-width evidence, 7/5 evidence-analysis split, timeline,
  native chart, native table, or sparse decision slide.
- Prefer flat editorial layouts. Do not repeat dense dashboard cards.
- Use color as semantics: teal = supported/complete; amber = pending/decision;
  terracotta = risk/contradiction.
- Place slide number and time estimate in a quiet footer.

## Evidence rules

- Every chart declares unit, baseline, and synthetic/observed status.
- Every external claim has a compact page citation and a full source-register entry.
- Any inference is labeled as interpretation, not reported fact.
