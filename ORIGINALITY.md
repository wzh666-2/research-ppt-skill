# Originality and source policy / 原创性与来源政策

This project is independently implemented. Two privately supplied SciDraw
presentations were inspected only to understand abstract presentation
principles such as whitespace, hierarchy, information density, and narrative
rhythm. The repository does **not** contain those files, their unpacked
contents, master layouts, exact geometry, themes, images, icons, sample data,
or wording.

本项目为独立实现。两份私人提供的 SciDraw 演示稿只用于分析留白、层级、信息密度和叙事节奏等抽象原则；仓库不包含原文件、解包内容、母版、精确坐标、主题、图片、图标、示例数据或文案。

## Independent visual system

- Warm ivory canvas, ink-navy typography, teal emphasis, amber status cues.
- Twelve-column alignment logic with asymmetrical editorial layouts.
- Conclusion-led slide titles, sparse evidence, and explicit decision prompts.
- Original synthetic examples; no real paper figures or reference-template assets.

## Figure and citation rules

Paper figures are not embedded by default. Prefer an original redraw from
reported values. A source image may be embedded only when the user explicitly
requests it and the spec records its source, license status, and risk note.
Unknown license status is shown as a visible warning, never silently assumed.

## Practical assurance

The project provides independent creation, provenance fields, repository
exclusions, and similarity checks. These are technical safeguards, not an
absolute legal warranty. Users remain responsible for confirming permissions
for materials they add.

SciDraw's public pages state restrictions on redistribution and derivative use;
the project therefore contains no SciDraw template or derivative asset:

- https://sci-draw.com/zh/scientific-presentation-templates
- https://sci-draw.com/terms
